ساعي البيتزا - مشروع أندرويد (WebView)
=======================================

الطريقة 1 (الأسهل، من غير ما تنزّل حاجة على الكمبيوتر): GitHub Actions
1. اعمل حساب على github.com (مجاني) واعمل Repository جديد (Private أو Public).
2. ارفع كل محتويات الفولدر ده (بما فيهم فولدر .github) على الـ Repository.
   لو الفولدر المخفي .github مش ظاهر عندك، فعّل Show hidden files.
3. افتح تبويب Actions واختار "Build APK" واضغط Run workflow (أو هيشتغل لوحده بعد الرفع).
4. بعد دقايق افتح الـ run، ونزّل الملف PizzaRush-APK من قسم Artifacts. جواه app-debug.apk.
5. ابعت الملف لتليفونك، وافتحه، ولو طلب اسمح بالتثبيت من مصادر غير معروفة.

الطريقة 2: Android Studio
1. نزّل three.min.js (النسخة r128) من:
   https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
   وحطه في app/src/main/assets/ بنفس الاسم three.min.js
2. افتح الفولدر في Android Studio، وانتظر الـ Sync.
3. Build > Build APK(s). الملف بيطلع في app/build/outputs/apk/debug/

ملحوظات
- اللعبة بتشتغل أوفلاين بعد التثبيت (الخطوط الاختيارية بتتحمّل لما يكون في نت).
- الحفظ (العملات والمتجر) بيتخزن جوه التطبيق.
- زرار الرجوع في التليفون بيعمل إيقاف مؤقت أثناء اللعب.

لو ظهرت رسالة "تعذر تحميل اللعبة" جوه التطبيق: صوّر الشاشة وابعتها، فيها سبب الخطأ بالظبط.
لو لقيت مستطيل أحمر تحت في الشاشة: ده خطأ في الكود، صوّره وابعته برضه.
